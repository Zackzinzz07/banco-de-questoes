# Banco de Questões de Concursos Públicos

Este repositório hospeda o projeto **[banco_questoes](banco_questoes/)** — coleta,
taxonomia, armazenamento e geração de simulados em PDF para concursos públicos
brasileiros.

## 👉 A documentação completa fica em [`banco_questoes/README.md`](banco_questoes/README.md)

Lá estão a visão geral, a arquitetura em camadas, o guia de instalação, o motor
multi-banca de simulados e as métricas atuais do acervo.
